# SpotDrop Malta – Instagram landing page

A static, mobile-friendly entry page linking to the SpotDrop Google Play listing and web app.

- Page: `index.html`
- Hosting: GitHub Pages, from branch `spotdrop-malta`, root `/`
- App code: maintained separately in the private `spotdrop` repository
- Build: none. No Emergent credits or external dependencies.

## Activate GitHub Pages

Open **Settings → Pages**, select **Deploy from a branch**, choose **spotdrop-malta**, select **/(root)** and **Save**. Then visit `https://gatopardo123.github.io/SpotdropLINK/` and test the buttons from the Instagram in-app browser before posting it in the bio.

## Note

A landing page does not guarantee the Play Store will open from Instagram. It includes instructions for opening the external browser and a copy-link fallback.
